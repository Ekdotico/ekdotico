# 0001 — Next.js 16

- **Date:** 3 September 2026 (founder decision); transferred here on 7 October 2026, at repository initialisation.
- **Requirement:** NFR-IC-01.

The framework lock moved from Next.js 14 to Next.js 16. NFR-IC-01 records the decision in its own text and says that it "is transferred to the ADR log as its first entry at repository initialisation". This is that entry; the reasons are in the requirement.

The repository is initialised on Next.js 16.4.0, with React 19.2.8, since NFR-IC-01 locks React 19.2.
